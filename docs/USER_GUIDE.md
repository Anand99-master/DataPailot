# DataPilot User Guide

DataPilot provides an end-to-end analytics workspace structured around the core workflow:
> **Import Data → Data Quality → Cleaning & Transformation → Pipeline → SQL / Analysis → Visualization → Dashboard → Reports / Sharing**

---

## 1. Core Workflow Steps

1. **Import Data**: Upload CSV, XLSX, or JSON files. DataPilot automatically detects columns, data types, and registers tables in the Unified Data Layer.
2. **Data Quality**: Review automated profiling metrics, missing value percentages, duplicate rows, and outlier detection.
3. **Cleaning & Transformation**: Apply non-destructive data cleaning operations (trim whitespace, replace missing values, change data types, normalize case).
4. **Pipeline**: View ordered transformation steps, reorder, version, or undo/redo actions.
5. **SQL / Analysis**: Write and execute secure read-only SQL queries with autocomplete, snippets, and execution history.
6. **Visualization**: Build charts (bar, line, scatter, pie) from query results with grouping and aggregation.
7. **Dashboard**: Arrange multiple visualization widgets into a unified dashboard with global filters.
8. **Reports & Sharing**: Capture immutable snapshots, generate narrative insights, and share with team members using Role-Based Access Control (RBAC).

---

## 2. Advanced Features

- **Saved Queries & Snippets**: Save reusable SQL templates and parameters.
- **Data Lineage**: Trace column and table origins across transformation steps.
- **Global Cross-Filtering**: Filter dashboard widgets simultaneously by category or date range.
- **Secure Export**: Export cleaned datasets to CSV, Excel, or JSON with formula injection protection.
